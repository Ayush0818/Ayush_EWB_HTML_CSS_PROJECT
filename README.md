## 📖 About The Project

This is my **Personal Portfolio Website** — a submission for the **EWB HTML & CSS Internship Project**. The goal was to plan, build, style, test, and submit a responsive portfolio website that introduces me, presents my skills and projects, and provides contact information.

> **Constraint:** Built with **HTML5 and CSS3 only** — no JavaScript, no React, no Bootstrap, no backend.


## 🎨 Design System

### Colour Palette

| Variable | Hex | Usage |
|---|---|---|
| `--clr-bg` | `#0d1117` | Main background |
| `--clr-bg-2` | `#161b22` | Card / section background |
| `--clr-bg-3` | `#1f2937` | Input / nested background |
| `--clr-accent` | `#58a6ff` | Primary accent (blue) |
| `--clr-accent-2` | `#3b82f6` | Button background |
| `--clr-green` | `#3fb950` | Success / highlights |
| `--clr-purple` | `#a371f7` | Secondary accent |
| `--clr-text` | `#e6edf3` | Primary text |
| `--clr-text-muted` | `#8b949e` | Secondary text |

### Typography
- **Font**: `'Segoe UI'`, `system-ui`, `-apple-system`, `sans-serif`
- **Mono Font**: `'Cascadia Code'`, `'Fira Code'` (tech tags)
- **Scale**: `clamp()` for fluid, responsive font sizes

### CSS Features Used
```css
/* CSS Variables */       :root { --clr-accent: #58a6ff; }
/* Flexbox */             display: flex; gap: ...;
/* CSS Grid */            display: grid; grid-template-columns: repeat(auto-fit, ...);
/* Media Queries */       @media (max-width: 640px) { ... }
/* Animations */          @keyframes spin { ... } @keyframes pulse { ... }
/* Pseudo-elements */     ::before, ::after, ::placeholder
/* Clamp */               font-size: clamp(1.8rem, 4vw, 2.6rem);
/* Custom Properties */   var(--clr-accent), var(--transition)
/* Backdrop Filter */     backdrop-filter: blur(12px);
```

## 🚀 Getting Started

No build tools, no npm, no setup required!

```bash

# 2. Open the project folder
cd Ayush_EWB_HTML_CSS_PROJECT
```
